# ExpertTester

This repo holds only ExpertTester's installer and its updates. It has no
source code.

## Install

1. Download
   [ExpertTesterApp-win-Setup.exe](https://github.com/YoussefMaximous/ExpertTester-Releases/releases/latest/download/ExpertTesterApp-win-Setup.exe).
2. Run it. The installer isn't signed, so Windows may say "Windows protected
   your PC": choose **More info**, then **Run anyway**.
3. ExpertTester installs for your Windows user (no admin rights), puts a
   shortcut on your desktop and in the Start menu, and opens.

Windows 10 or 11, 64-bit.

## Updates

When a new version is out, ExpertTester offers it when it starts, or use
Help › Check for Updates…. You choose when to install it.

Updates never touch your sessions, experts or tick data: they stay in
`%LOCALAPPDATA%\ExpertTester`.

## Uninstall

Windows Settings › Apps › Installed apps › ExpertTester › Uninstall. Your data
folder stays.
